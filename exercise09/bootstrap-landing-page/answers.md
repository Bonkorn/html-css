# Bootstrap landing page: my answers

## 1. Which Bootstrap classes did you use for the navbar?
`<nav class="navbar navbar-expand-lg bg-white border-bottom sticky-top">`

## 2. Which value on the navbar button points to the menu?
data-bs-target="#myMenu" and aria-controls="myMenu" points to `<div class="collapse navbar-collapse" id="myMenu">`

## 3. Which grid classes changed the layout of the hero section?
container, row , align-items-center , g-4 , col-lg-6

## 4. Which card classes did you use?
card, card-body, card-title, card-text

## 5. Which styles did you put in `custom.css`, and not as Bootstrap utility classes in the HTML?
gradient background for .hero-section , typography for .eyebrow, border and corners for .info-panel & .service-card , light background for .contact-section , dark background for .site-footer
