# Portfolio image hero: my answers

## 1. Which image goes in the HTML, and why?
images/portfolio-desk.png , it use `<img>` tag because its part of the page content, that help explain the portfolio easily, and if the image fails to load or those using screen reader, the text in the alt attribute will be loaded instead

## 2. Which image goes in the CSS, and why?
images/portfolio-background.png , goes in the background-image for decorative purposes, the page content can still make sense even without this background decoration

## 3. Which CSS property stops the content image from stretching?
object-fit: cover

## 4. Which element makes the boundary for the positioned label?
image-panel

## 5. What did you do to keep the text easy to read?
i added background-color: rgba(255, 255, 255, 0.93); in .hero-content
