# Typography: my answers

## 1. Which text must the reader see first?
"Build your first CSS habit.", because it's on top with the largest heading (h1 selector)

## 2. Which CSS choice makes that text the strongest?
`h1 { font-size: 3rem; line-height: 1.05; }`

## 3. Which text is supporting information?
for example, it's "Join a short practice session where each CSS change gets saved, refreshed, and checked in the browser.", because it's the paragraph, and it uses softer color and smaller font size than the largest heading `.feature-intro { color: #57534e; font-size: 1.2rem; }`

## 4. Which color is used for an action or for emphasis?
#c2410c, used in .kicker , .primary-action , .secondary-action , .session-meta

## 5. Which spacing choice separates one content group from another?
`.feature-panel { margin-bottom: 56px; }` and `.session-list { gap: 20px; }`
